Start from scratch. A windows winforms c# program, a program to find .jpg, .jpeg and .jfif files that are in fact other images files (.webp, .png, .avif or .bmp). The check must me made using the magic header of the files. The interface must have a button to set directory to search in, a editable text box with the directory to search in, an checkbox to search in subdirectory, an input number to limit search by number of weeks (0 means no limit, 1 means 1 week maximum files...) and the results must be displayed in a array with name, file size, file dimensions (with x height) and date. Add also a column for real file type. Double clicking on a line must launch the file with the start command. By selecting multiple lines and clicking on a "copy" button, the original names must be copied in clipboard, one file by line. The search must be interruptible with a button "Stop", if so the already results found must be displayed. Search path, recursive chekbox status and weeks filter must be saved in an .ini file. Values must be loaded at program launch and saved when launching search.
Detect also empty files and mark them as empty. Detect also unknown files and mark them too. Add a timer that start when search start and stop when search is finished or is cancelled. The timer must be displayed on the left of mimatches and must remains after search.
